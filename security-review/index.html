Reef's contracts are Uniswap V2 ported to Solidity 0.8 with the names changed; the logic was compared line by line with the original. Nobody, including the developer, can pause Reef, freeze a pool or move funds out of one. On Handshake, the owner has no function that touches a live offer's funds.

How it was done

  1. Every contract read line by line; Reef compared with Uniswap V2's published code.
  2. Slither, the standard automated analyser, run on every contract with the deployed compiler settings, and each flag checked by hand.
  3. Tests written for anything that looked wrong, so findings are shown to be real, not guessed. 64 tests pass, covering normal use, attacks and random sequences of trades.
  4. Each address's code read from chain on 2 October 2026 and compared with what the published source compiles to.

Not covered: the $REEF token and presale contracts, the NOCAP token, the websites (except where they set a swap's minimum output), the BlockDAG chain itself, and anything deployed after 2 October 2026.
