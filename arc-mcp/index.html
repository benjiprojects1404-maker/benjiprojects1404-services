Connect it

One URL, no account. Pick your app.

Claude (web, desktop or phone)

Settings → Connectors → Add custom connector. Name it Arc and paste the endpoint above. Then just ask about Arc in any chat.

Claude Code

claude mcp add --transport http arc https://arc-mcp.benjiprojects1404.workers.dev/mcp

Cursor, VS Code and other MCP apps

Add a remote (streamable HTTP) server to the app's MCP config:

{
  "mcpServers": {
    "arc": { "url": "https://arc-mcp.benjiprojects1404.workers.dev/mcp" }
  }
}

Your own agent

It's plain JSON-RPC over HTTPS. List the tools:

curl -s -X POST https://arc-mcp.benjiprojects1404.workers.dev/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
